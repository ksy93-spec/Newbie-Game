# 뉴비 퀘스트 출시 로드맵 (CTO)

기준일 2026-09-29. 팀별 상세는 같은 폴더의 ads.md, dev.md, marketing.md, cs.md, cx.md.

## 목표와 현실

- 목표는 무료 앱 광고 수익으로 월 300만원 이상.
- 광고 단가가 AdMob 실측으로 확인될 때까지는 전부 추정치다. 추정대로라면 월 300만원에 필요한 DAU는 보수 약 18,000 / 중간 약 4,500 / 낙관 약 1,750이다.
- 마케팅 0원(오가닉)으로 첫 6주 안에 닿을 수치는 아니다. 6주 목표는 작동 검증(설치 1,500, D1 30% 이상, D7 8% 이상)으로 잡고, DAU 1,000 → 4,500을 두 단계 목표로 둔다.
- 병목은 광고 단가가 아니라 설치 수와 재방문이다.

## 운영 방식

- CTO(Opus)가 우선순위와 품질을 정하고 결과를 합친다. 실무는 Sonnet 에이전트 다섯이 맡는다.
  - 제품개발
  - 광고
  - 마케팅
  - CS
  - 고객경험
- 에이전트에게는 좁은 과제, 분량 상한, 검색 횟수 상한을 준다. 결과는 파일로 받는다.
- 주인(대표)에게는 되돌리기 어려운 결정만 묻는다. 돈, 계정·명의, 법적 위험, 방향 전환이 여기에 해당한다.

## 대표가 직접 해야 하는 것

에이전트가 대신할 수 없고, 계정과 결제가 필요한 일이다.

1. 구글 플레이 개발자 계정: $25, 신원 확인.
1-1. 애플 개발자 프로그램(개인): 연 $99. 가입 후 App Store Connect에서 앱 등록과 API 키 발급.
2. AdMob 계정과 결제 프로필.
3. Expo 계정: 무료, EAS 클라우드 빌드용.
4. 지원용 이메일 주소 하나.
5. 회사 취업규칙의 겸업 조항 확인. 명의와 세금은 cs.md의 체크리스트대로 세무사에게 한 번 확인.
6. 비공개 테스터로 지인 20명 섭외.
