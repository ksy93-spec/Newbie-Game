# 메인 퀘스트 통합본 플레이 시험 (QA 2차, 2026-10-01)

대상은 작업 폴더의 `prototype/newbie-quest-demo.html`(통합본, 11602줄)이다. 게임·테스트 파일은 고치지 않았다. 시험 스크립트는 스크래치 폴더에만 두었다. 심각도는 막힘(진행 불가), 불편(진행은 되나 규칙이 새거나 헷갈림), 다듬기(글·표시) 셋으로 나눈다.

## 1. 자동 테스트

`npm test`: 115개 통과, 실패 0, 88.1초. 1차 때 작업 사본에서 실패하던 sprintC2 3번(하루의 끝 시트)도 이제 통과한다.

## 2. 플레이 방법

Playwright로 새 사용자를 만들어 1장부터 6장까지 차례로 했다. 360×640은 모든 선택을 정답으로, 390×844는 모든 선택을 오답으로 했다. 2장은 진짜 전세 사건으로 했다. `tierMove(7)` → 부동산 → 주택가 → 부동산 → 주택가 → 주민센터 → 결말 화면 "새 집으로" → 끝맺음 컷신 순서다. 6장 앞에서는 `tierMove(8)`로 투룸 전세 계약(다섯 편)도 끝까지 했다. 날짜는 `Date.now`를 하루씩 밀고 저장을 확인한 뒤 새로고침했다. 그래서 날마다 새 세션이 열리고 할배 알림이 다시 돈다.

시간을 줄이려고 두 가지를 손으로 맞췄다. 원룸 전세가 열리도록 `S.peak=7, ju=45`, 장마다 필요한 레벨(Lv.6/8/10)이다. 그리고 아래 3.1의 부팅 오류를 피하려고, 투룸 전 하루를 넘길 때 주 스탯을 47로 눌러 두었다.

## 3. 발견한 것

### 3.1 막힘: 새 날 첫 실행에서 게임이 안 열린다 (부팅 오류)

- 증상: 홈이 안 뜨고 온보딩 화면에 멈춘다. 콘솔에 `TypeError: Cannot read properties of undefined (reading '7')`(또는 `'8'`)가 찍힌다. 저장이 되기 전에 멈추므로 켤 때마다 같은 오류가 나서 영구히 못 들어간다.
- 원인: 부팅 순서. `S=load(); rollDay();`(9079~9081줄)가 `rollDay` → `tierGrow` → `tierMove` → `leaseGate`(11477줄)를 부른다. 그런데 `var LEASE_TIERS={7:1,8:1}`는 그보다 아래에서 값을 받으므로, 이 시점에는 아직 `undefined`다. `leaseGate` 첫 줄의 `LEASE_TIERS[i]`에서 터진다.
- 걸리는 조건: 하루가 바뀐 첫 실행에서 `tierGrow`가 원룸 전세(7)나 투룸 전세(8)를 열고, 지금 사는 곳이 맨 위(`tier===peak`)라 바로 옮기려 할 때.
- 메인 퀘스트와의 관계: 2장 good 보상이 주 +6이다. 원룸 전세(주 42)로 막 옮긴 사람이 주 48을 넘기 쉽고, 그러면 다음 날 투룸 전세를 열려다 터진다. 이번 플레이에서도 2장을 정답으로 깬 다음 날 바로 걸렸다.
- 재현: 저장을 `ju=45, peak=6, tier=6, paid=6, S.day=어제, upDay=null`로 두고 새로고침한다.
- 범위: HEAD(커밋된 판)에서도 똑같이 재현된다. 스프린트 D부터 있던 문제다. 테스트는 날짜를 넘겨 새로고침하는 경우를 안 다뤄서 못 잡았다.
- 고칠 곳: `LEASE_TIERS` 선언을 `S=load()` 위로 올리거나, `leaseGate`에서 `typeof LEASE_TIERS` 를 먼저 본다.
- 더할 테스트: 위 저장으로 새로고침했을 때 콘솔 오류가 없고, 홈이 뜨고, `S.lease.to===7`인지 본다.

### 3.2 불편: 캐릭터 창에서는 잠긴 물건을 그냥 살 수 있다

- 증상: 1장 전인데 캐릭터 탭에서 탈것 칸의 중고 경차를 누르면 상세 시트에 "￦900에 사기"가 켜져 있다. 누르면 900이 빠지고 차를 갖고 탄다.
- 결과: 찻길은 다닌다. 고속도로 입구에서는 "고속도로는 메인 4장 「첫 차」를 마치면 열려요"로 막힌다. 4장 보상 "열림 · 자동차 구매"가 의미를 잃고, 튜토리얼 'car' 단계는 "고속도로로 나가 봐"라고 말한다.
- 원인: `mqShopLock`은 `itemRow`의 상점 모드(8015줄)에서만 본다. `gearTip`의 사기 버튼(8211~8213줄)은 장 잠금을 보지 않는다. 같은 길로 출근복(oxford·cardigan·wideslk), 카드지갑, 법인카드, 세단, 소형 전기차도 살 수 있다.
- 재현: `S.mq={done:{},gf:{}}`, 코인 2000으로 시작한다. `render('char'); gearTip('mount','car')`를 열고 사기를 누르면 `S.owned`에 car가 들어간다.
- 고칠 곳: `gearTip`에서 `mqShopLock(slot,id)`가 있으면 버튼을 끄고 그 문구를 보여 준다.

### 3.3 불편: 6장을 ok·bad로 깨면 자가가 바로 안 열린다

- 증상: 오답 판(bad)으로 6장을 깨면 보상 카드와 완료 시트에 "열림 · 자가 거처"가 뜨지만 `peak`은 8 그대로다. 메인 칩은 모든 장을 마쳐서 사라지므로, 주 스탯이 54가 돼야 열린다는 안내가 어디에도 없다.
- 정답 판(good)은 주 +10을 받아 "새 거처 · 도시형생활주택 입주"가 나왔다.
- 원인: `mqPay`의 home 처리는 그날 몫(`upN`)만 하나 돌려주고 `tierGrow()`를 부른다. `tierGrow`는 `tierFor(ju)>peak`일 때만 열고, 도시형생활주택은 주 54가 필요하다. bad 보상은 주 +3이다.
- 고칠 곳: 둘 중 하나로 정한다.
  - 6장을 깨면 9단계를 주 스탯과 상관없이 연다.
  - 열리지 않았을 때는 시트에 "주 스탯 54가 되면 도시형생활주택이 열려요"를 쓴다.

### 3.4 불편: 다른 창에 막힌 할배 알림은 그 세션에서 다시 안 뜬다

- 증상: 3일째(연속 3일 보상이 있는 날) 4장 조건을 채우고 홈에 있었는데 알림이 끝내 안 떴다. 두 크기 모두 같았다. 칩은 "눌러서 시작"으로 깜박인다.
- 원인: `mqAnnounce`는 `renderHome` 2.6초 뒤와 `openingEnd` 뒤에만 돈다. 그 순간 `todayAuto`가 띄운 오늘 할 일 시트(`#itip`)가 열려 있으면 `mqIdle()`이 거짓이라 그냥 물러난다. 시트를 닫아도 다시 부르지 않는다.
- 고칠 곳: `closeTip` 뒤에, 또는 칩을 그릴 때 한 번 더 `mqAnnounce`를 건다. `MQ_SAID`가 세션 한 번을 지키므로 겹칠 걱정은 없다.

### 3.5 다듬기

1. bad·ok 등급에도 클리어 카드와 완료 시트가 좋은 결말 문구(`MQ_COPY[id].card`)를 그대로 쓴다. 2장을 bad로 끝내면 "보증금이 묶였다" 결말 바로 뒤 카드가 "보증금은 서류가 지켜 준다."다. 등급별 둘째 줄을 두거나, bad일 때는 둘째 줄을 빼는 편이 맞다.
2. 2장 칩: 이사부터 시도해서(`tierMove(7)`) 계약 사건이 이미 열렸는데도 칩은 "메인 2장 첫 전세 계약 / 눌러서 시작"이다. `mqLeasing()`이 `S.mq.cur==='lease'`를 보는데, 이 값은 앞 컷신을 본 뒤에야 생긴다. 눌러도 문제는 없다(앞 컷신 → 부동산 중개사 앞). 다만 "부동산에서 계약 시작"이 더 맞다.
3. 1장 완료 시트의 "다음은 2장 첫 전세 계약 · 원룸 전세 해금까지 주 25"(`MQ_LIST` lease의 `wait`)는 "주 스탯 25 더"가 읽기 쉽다.
4. 상점 세간 줄은 잠겨도 버튼이 켜진 채이고, 누르면 토스트로 막는다(`buyFurni` 4572줄). 장비 줄은 잠기면 꺼진다. 같은 화면에서 모양이 다르다.
5. 옛 저장 가운데 이미 전세 계약을 해 본 사람(`leaseDone`, `paid>=7`)도 2장 회상을 보기 전까지 대형 가전(fridge2, purifier)이 잠긴다. `mqGrandfather`가 lease를 다루지 않아서다. 회상이 짧아 큰 문제는 아니지만, 가진 집에 맞는 가전을 못 사는 것이 어색할 수 있다.

## 5. 다음에 더할 자동 테스트

1. 3.1 회귀: 날짜를 하루 넘긴 저장(`tier=peak=6, ju≥42` 또는 `tier=peak=7, ju≥48`)으로 새로고침하면 오류가 없고 홈이 뜬다.
2. 3.2 회귀: 장을 깨기 전 `gearTip`으로 연 장 잠금 물건(car, oxford, wallet)의 사기 버튼이 꺼져 있다.
3. 3.3: bad로 6장을 깬 뒤 9단계가 열리거나, 열리지 않으면 시트에 필요한 주 스탯이 나온다.
4. 3.4: 알림 조건과 오늘 할 일 시트가 같이 있을 때, 시트를 닫으면 알림이 뜬다.

## 6. 반영 (CTO, 같은 날)

- 3.1 `LEASE_TIERS` 선언을 `S=load()` 위로 옮겼다. sprintE 7번이 하루 넘긴 저장으로 새로고침해서 확인한다. 옛 코드에서는 이 테스트가 실패한다.
- 3.2 `gearTip`도 `mqShopLock`을 본다. 잠긴 물건은 "아직 못 삼" 버튼이 꺼진 채로 나오고 이유 한 줄이 붙는다(sprintE 8번).
- 3.3 6장을 처음 깨면 등급과 주 스탯에 상관없이 9단계(도시형생활주택)를 연다. 맨 위 거처에 살고 있으면 보증금을 내고 바로 옮긴다(sprintE 9번).
- 3.4 시트(`closeTip`)나 대화(`endTalk`)가 닫힌 뒤 할배 알림을 한 번 더 시도한다(sprintE 10번).
- 3.5-1 bad 등급이면 클리어 카드와 완료 시트에서 교훈 문구를 빼고 "N장 · 제목"을 쓴다.
- 3.5-2 전세 계약이 이미 열렸으면 칩이 "눌러서 계약 시작"이라고 쓴다.
