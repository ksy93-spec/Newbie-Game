# 메인 퀘스트 브리프 (2026-10-01, CTO)

에이전트 여섯이 같은 약속을 보고 일하도록 적는다. 게임 본체는 `prototype/newbie-quest-demo.html` 한 파일이고, 이번 회의에서는 에이전트가 이 파일을 고치지 않는다. 각자 `ops/meeting-1001/` 아래 자기 파일만 만든다. 엔진과 통합은 CTO가 한다.

## 요청 (대표)

게임의 큰 줄기를 잇는 메인 퀘스트를 만든다. 할배가 메시지 창으로 "다음 할 일"을 알려 주고, 시작하면 오프닝·프롤로그처럼 영상(컷신) 위주로 진행한다. 보상은 메인답게 크게 주고, 깨면 갈 수 있는 지역이 넓어지거나 살 수 있는 것이 늘어난다. 내용은 사회초년생이 겪는 큰일들이다.

## 장 구성 (초안, CX·경제가 다듬는다)

| 장 | id | 제목 | 여는 조건(초안) | 깨면 열리는 것(초안) |
|---|---|---|---|---|
| 1 | job | 첫 취업 | 튜토리얼 뒤 퀘스트 3개 완료 | 역 앞 지역, 출근복 상점 칸 |
| 2 | lease | 첫 전세 계약 | 1장 완료 + 전세 거처(원룸 전세) 해금 | 대형 가전 세간 |
| 3 | card | 첫 신용카드 | 2장 완료 | 은행 골목 관련 혜택, 카드 장비 |
| 4 | car | 첫 차 | 3장 완료 | 자동차 구매, 고속도로와 전국 여행(강릉·전주·부산) |
| 5 | wedding | 결혼 준비 | 4장 완료 | 경주·대구(상견례·신혼여행), 신혼 세간 |
| 6 | home | 첫 내 집 마련 | 5장 완료 + 투룸 전세 | 자가 거처(9단계~) 해금, 엔딩으로 이어짐 |

2장은 스프린트 D의 전세 계약 사건(`LEASE_CH`, 부동산 → 매물 → 부동산 → 주민센터)을 그대로 쓰고, 장면을 컷신 플레이어로 보여 준다. 새로 쓸 것은 2장 앞뒤의 컷신뿐이다.

## 컷신 대본 형식

대본은 순수 JS 객체 하나다. 파일 이름은 `ops/meeting-1001/ch-<id>.js`, 안에는 `var MQ_<ID> = {...};` 한 줄 선언만 둔다(import·export 없음).

```js
var MQ_JOB = {
  id: 'job', no: 1, title: '첫 취업', sub: '합격 문자부터 첫 월급까지',
  asof: '2026-10',
  src: [['고용노동부', 'https://www.moel.go.kr'], ['국민연금공단', 'https://www.nps.or.kr']],
  scenes: [
    { bg: 'phone', text: ['[문자] 최종 합격을 축하드립니다.', '월요일 9시까지 출근 바랍니다.'], fx: 'flash' },
    { bg: 'office', cast: [['hero', 'L'], ['officem', 'R']], who: '인사팀 과장', text: ['어서 와요. 계약서부터 쓰죠.'] },
    { bg: 'meeting', cast: [['hero', 'L'], ['officem', 'R']],
      doc: { t: '근로계약서', rows: [['임금', '월 250만 원'], ['수습', '3개월'], ['근로시간', '주 40시간']], bad: [] },
      who: '인사팀 과장', text: ['여기 서명만 하시면 돼요.'],
      choice: { opts: [
        { a: '항목을 다 읽고 한 부 받는다', ok: 1, note: '근로계약서는 서면으로 쓰고 근로자에게 한 부를 줘야 한다.' },
        { a: '바쁘니 서명만 한다', ok: 0, note: '적힌 조건이 나중의 유일한 증거다. 읽지 않은 서명은 내 편이 아니다.' } ] } },
    { bg: 'office', cast: [['gpa', 'R'], ['hero', 'L']], who: '귀인 할배', text: ['허허, 잘했네.'] }
  ],
  ends: {
    good: ['계약서 한 장, 명세서 한 장.', '첫 월급을 제대로 받았다.'],
    ok: ['큰 탈은 없었지만 몇 가지를 놓쳤다.'],
    bad: ['모르고 넘어간 것들이 월급에서 조용히 빠져나갔다.']
  }
};
```

필드 설명

- `bg`: 배경 이름. 아래 목록에서만 고른다.
- `cast`: 화면에 세울 사람 `[열쇠, 자리]`. 열쇠는 `hero`(나), `gpa`(귀인 할배), `partner`(결혼 상대, 성별은 엔진이 나에 맞춰 고른다), 그리고 `gma peerm peerf deskf officem boss mlmf fp boy girl`. 자리는 `L`, `C`, `R`.
- `who`: 말하는 사람 이름. 없으면 해설.
- `text`: 한 줄 18자 안팎, 한 장면에 세 줄까지. 길면 장면을 나눈다. 화면이 가로 160칸이라 넘치면 잘린다.
- `doc`: 화면에 뜨는 서류 카드. `t` 제목, `rows` 최대 4줄(`[항목, 값]`, 값은 12자 안팎), `bad`는 빨간색으로 칠할 줄 번호(0부터).
- `choice`: 보기 2~3개. 보기 `a`는 22자 안쪽, `ok`는 1(맞음)이나 0, `note`는 고른 뒤 뜨는 해설로 80자 안쪽. 장마다 선택은 3~4개.
- `fx`: 연출. `flash`(번쩍), `shake`(흔들림), `money+`·`money-`(돈이 오르내리는 숫자, `amt`에 금액 문자열), `stamp`(도장 쾅), `confetti`(축하), `rain`(비), `fade`(암전 뒤 밝아짐).
- `ends`: 정답 수로 갈리는 마지막 대사. 전부 맞히면 good, 절반 이상 ok, 그 아래 bad.

배경 목록(개발 리드가 그린다): `night`, `phone`, `office`, `meeting`, `bank`, `carlot`, `road`, `weddinghall`, `cafe`, `modelhouse`, `apartment`, `livingroom`, `town`, `station`.

장마다 장면 12~18개, 선택 3~4개. 할배는 첫 장면이나 끝 장면에 한 번은 나온다.

## 글과 사실

- 대사는 게임 말투로 짧게. 기존 대사(`TALKS`, `LEASE_CH`, `PROLOGUE`)를 읽고 톤을 맞춘다.
- 숫자·제도는 2026년 10월 기준으로 공식 출처를 웹에서 직접 확인한다. 확인 못 한 숫자는 쓰지 않는다. 자주 바뀌는 숫자는 "확인하자"로 쓴다.
- 대본 파일 맨 위 주석에 확인한 출처와 날짜를 적는다.
- 공포 조장, 특정 회사·브랜드 이름, 실존 인물은 쓰지 않는다.
