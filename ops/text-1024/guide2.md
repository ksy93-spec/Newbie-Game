# 2차 다듬기 기준 (im-not-ai 규칙)

1. 먼저 `ops/text-1024/guide.md`를 읽는다. 거기 "절대 지킬 것"이 이 문서보다 우선한다.
   - 사실·숫자·이름·자리표시·태그를 보존한다.
   - 퀴즈 정답을 바꾸지 않는다.
   - 인물 말투를 지킨다. 할배 사투리와 하게체, 안내는 해요체, 나레이션은 "~다".
   - 14자 이하 줄은 고친 뒤에도 14자 이하로 둔다.
2. 그다음 `ops/text-1024/im-not-ai/quick-rules.md`(im-not-ai, MIT)를 읽고 그 패턴 ID 기준으로 고친다. 게임 문장은 짧아서 "문서당 n회" 같은 빈도 규칙은 묶음 전체를 한 문서로 보고 판단한다.
3. 짧은 게임 문장에서 특히 볼 것:
   - A-3·A-5·A-7·A-8·A-9 번역투
   - C-11 연결어미(-고/-며/-지만/-면서/-아서/-어서) 바로 뒤 쉼표. 짧은 문장에서는 지운다.
   - D-8 "중요한 것은 ~이다", "핵심은 ~다" 같은 분열문
   - I-3 "~다는 것이다", "~다는 뜻이다"
   - E-7 한 문장 안에서 존댓말 등급이 섞인 것
   - F-5 "~적 N" 추상 체인
   - D-2 의의 과장
4. 서법 보존: "~해야 한다"를 "~한다"로 바꾸지 않는다. "~일 수 있다"를 단정으로 바꾸지 않는다. 의학·법률·정책 설명의 유보 표현은 그대로 둔다.
5. 변경률: 한 문장을 30% 넘게 고치지 않는다. 확신이 없으면 그대로 둔다.
6. 결과는 `ops/text-1024/out2/cNN.json`에 `{"T123": "고친 문장"}` 형식으로, 바꾼 것만 쓴다.
