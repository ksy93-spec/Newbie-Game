도트 그림과 갈무리 글꼴 위에 둥근 모서리·그라데이션·유리 효과 스킨(v2)을 덮어 두 가지 그림 언어가 섞였고, 지도는 정수 배율이 아니라 도트가 고르지 않으며, 글자 요소의 53%가 갈무리가 흐려지는 크기다. 홈 화면 위아래 틀이 화면의 36%를 먹고, 퀘스트 첫 문제는 360×640에서 보기가 하나도 안 보이며, 보상 순간은 숫자가 그냥 찍히고 끝난다. 설정과 수집 노트는 지도 위 가방을 눌러야만 들어간다.

## 1. 공통 문제

### C1. 그림 언어가 두 가지다 (도트 틀 + 둥근 유리 스킨) · 중간 · P1

- 문제: 기본 스타일은 3px 검은 테두리와 모서리 깎기(.pix)로 된 도트 틀인데, 579~671줄 "화면 스킨 v2"가 그 위에 둥근 모서리(10~28px), 그라데이션 20곳(linear 16, radial 4), backdrop-filter 3곳, 1px 연한 테두리와 흐린 그림자를 덮었다. 그래서 한 화면 안에서도 각진 도트 상자와 둥근 카드가 섞인다.
- 근거 [확인]
  - 오프닝 메뉴는 각진 도트 버튼(cx-opening-b-360.png)인데 바로 다음 온보딩은 둥근 유리 카드(cx-onboard-1sel-360.png).
  - 퀘스트 화면: 간파·막기 설명은 3px 각진 노란 상자, 바로 아래 보기는 둥근 회색 카드(cx-quest-q-390.png).
  - 결과 화면: 얻은 것 줄은 3px 각진 흰 상자, 버튼은 둥근 그라데이션(cx-result-win-360.png).
  - v2 블록에 쓰인 색 37개 중 35개가 :root의 잠긴 팔레트(12~23줄) 밖이다(#6BE38A, #3FBF6A, #FFD866, #FFB830, #E2DED5, #8E95C4 등).
  - 641줄 `.card,.wrow,.item,...{border-width:1px!important}`, 645줄 `.dlg,.explain{border-width:1px}` 때문에 해설 상자의 정답·오답 왼쪽 8px 띠(375~377줄)가 사라졌다(cx-quest-ans-360.png에서 왼쪽 선이 1px).
- 인기 도트 게임 [관례]: Stardew Valley(모바일 포함)는 나무색 9분할 틀 하나로 모든 창을 만들고, 카이로소프트 게임은 한 가지 두꺼운 외곽선 창을 모든 메뉴에 쓴다. 포켓몬 GBA 세대도 대화창·메뉴·전투 상자가 같은 틀이다. 창 모양이 하나라서 "한 세계" 느낌이 난다. 대표가 싫어한 "고딕체", "일러스트 주인공"과 같은 결의 문제(그림체가 섞임)라고 본다 [추측].
- 고칠 방법
  - v2를 지우지 말고 "도트 틀 하나"로 다시 쓴다. 판(패널) 규격: 테두리 3px var(--s4), 모서리는 기존 .pix 깎기 4px, 안쪽 아래 그림자 `inset 0 -4px 0 var(--p3)`, 바깥 그림자 `0 3px 0 var(--s4)`. 둥근 모서리, 그라데이션, backdrop-filter, rgba 그림자는 뺀다.
  - 짙은 남색 틀(HUD·탭·시트)은 유지하되 n0~n4를 팔레트에 정식으로 올린다(:root에 --n0 #0E1022 ~ --n4 #4A548F, 이미 580줄에 있음). 버튼 초록은 #6BE38A/#3FBF6A 대신 var(--g1)/var(--g3), 강조 노랑은 var(--y1)/var(--y3)로 되돌린다.
  - 버튼 규격: 높이 48px, 글자 Galmuri11 12px 굵게, 배경 var(--g1), 테두리 3px var(--s4), `box-shadow: inset 0 -5px 0 var(--g3), 0 4px 0 var(--s4)`(117~120줄 원래 값). 보조 버튼은 배경 var(--p0), 안쪽 그림자 var(--p3).
  - 645~646줄의 1px 덮어쓰기에서 .explain을 빼고 `.explain.good{border-left:8px solid var(--g1)} .explain.bad{border-left:8px solid var(--r1)}`를 되살린다.

### C2. 갈무리 글자의 절반이 흐린 크기다 · 중간 · P1

- 문제: 갈무리는 비트맵 글꼴이라 설계 크기의 정수배에서만 가장자리가 깨끗하다. 지금은 9, 10, 11, 12.5, 13, 14, 17px이 섞여 있고, 굵은 글씨가 없는 Galmuri14·Galmuri9에 font-weight 700을 걸어 가짜 굵기가 생긴다.
- 근거 [확인] 캔버스에 같은 문장을 그려 반투명 가장자리 비율을 셌다(0이면 깨끗함, tools/cx-metrics.json의 crisp).
  - Galmuri14: 15px와 30px만 0. 13px 0.85, 14px 0.67, 12px 0.98, 11px 0.96.
  - Galmuri11: 12px와 24px만 0(보통·굵게 모두). 10px 0.95, 11px 0.75, 13px 0.63, 9px 1.0.
  - Galmuri9: 10px와 20px만 0. 9px 0.70, 8px 0.97.
  - Galmuri14 굵게, Galmuri9 굵게는 어느 크기에서도 0이 아니다(0.5~0.9). 굵은 글꼴 파일은 Galmuri11뿐이다(7줄 font-weight:700).
  - 360 화면 36장의 글자 요소 1,010개 중 깨끗한 조합은 475개(47%). 많이 쓰인 흐린 조합: Galmuri9 9px 196개(상태 바 이름·장비 칸 이름·탭 이름), Galmuri11 10px 굵게 39개(대화 이름), Galmuri11 11px 37개(오늘 할 일·토스트·이동 목록), Galmuri11 10px 35개, Galmuri9 8px 34개(가방 칸 가격 표), Galmuri11 13px 굵게 32개(HUD 이름), Galmuri11 9px 굵게 32개(상태 바 숫자), Galmuri14 13px(십자키 화살표), Galmuri14 12.5px(작은 화면 대화창 본문, 315줄).
  - 배율 2 기기에서는 CSS 10px이 20 기기 픽셀이 되므로 위 표의 20px 값이 그대로 적용된다(Galmuri9 10px → 20 기기 픽셀 → 0). 배율 2.625 기기(412폭 안드로이드 다수)에서는 어떤 크기도 정수배가 아니라 조금씩 흐리다 [추측, 표에서 유추].
- 인기 도트 게임 [관례]: 도트 게임은 글꼴을 2~3단계 크기로만 쓴다(본문 하나, 작은 글 하나, 제목 하나). 굵기 대신 색이나 외곽선으로 강조한다.
- 고칠 방법: 글자 단계를 넷으로 묶는다.
  - 작은 글(보조 설명, 수치 단위): Galmuri9 10px 보통, 줄 높이 14px. 9px·8px는 모두 10px으로.
  - UI 글(버튼, 이름, 칩, 탭 이름): Galmuri11 12px(보통 또는 굵게), 줄 높이 16~18px. 10·11·13px Galmuri11은 모두 12px으로. 탭 이름(235줄, 지금 Galmuri9 9px)도 Galmuri11 12px.
  - 본문(대화, 문제, 해설): Galmuri14 15px 보통, 줄 높이 24px. 14px·12.5px·11px Galmuri14(305·315·360줄)는 15px으로. 공간이 모자라면 Galmuri11 12px으로 내린다.
  - 제목: Galmuri14 30px 또는 Galmuri11 24px 굵게. 17px(.ob-q, 663줄)은 15px으로, 20px 방어 숫자(612줄)는 24px으로.
  - Galmuri14·Galmuri9에 걸린 font-weight:700은 지우고, 강조는 색(var(--s4) 대 var(--s2))이나 Galmuri11 굵게로 바꾼다.
  - 회귀 테스트 하나를 추가하기를 권한다: 보이는 글자 요소의 (글꼴, 크기, 굵기)가 허용 목록 안에 있는지 확인(위 스크립트의 measure()를 그대로 쓸 수 있다).

- 엄지 닿는 곳 [추측]: 360×640을 한 손으로 쥐면 위쪽 4분의 1이 가장 멀다. 그런데 메인 장 칩(y 163~199), 퀘스트 화면 "나가기"(왼쪽 위 y 12~56)처럼 자주 누를 것이 위 왼쪽에 있다.
- 인기 도트 게임 [관례]: Stardew 모바일은 화면 어디를 눌러도 걷고, 조이스틱을 켜면 엄지 아래에 지름 약 120px의 원이 뜬다. 메뉴 버튼은 오른쪽 아래·오른쪽 위에 크게 둔다.
- 고칠 방법
  - 십자키: 버튼 44×44, 간격 0, 전체 132×132, left 12px bottom 12px. 이미 지도 누르기로 걷기가 되니(7625줄 bindScene) 설정에서 십자키 끄기를 둔다.
  - 이동 목록 줄: min-height 44px, 위아래 여백 10px, 줄 사이 6px.
  - 오늘 할 일: min-height 44px, 좌우 여백 16px.
  - 메인 장 칩: min-height 44px로 하고 위치를 아래 C6·H2의 "목표 줄"로 옮긴다.
  - 오프닝 메뉴: min-height 48px.
  - 출처 링크: 글자는 그대로 두고 `display:inline-block; padding:12px 4px; margin:-12px -4px`로 누르는 칸만 키운다.

### C4. 반응과 손맛(juice)이 약하다 · 중간 · P1

- 있는 것 [확인]: 효과음 9종과 진동(3329~3345줄, 사각파), 전투 가로 띠 전환(battleWipe, 퀘스트 시작부터 화면 전환까지 약 0.46초), 한 글자씩 찍기(17ms/글자), 피해 숫자 떠오름(.pop), 흔들기(.shake), 깜빡임(.blink), 결과 제목 pop. 버튼 누름(:active로 4px 내려감)도 있다.
- 없는 것 [확인]
  - 배경 음악이 없다(코드에 음악 재생 없음).
  - 탭을 바꿀 때 전환이 없다. go()(7714줄)가 display만 바꾼다. 상점 탭을 누르고 화면이 바뀌기까지 데스크톱에서 94~112ms 동안 메인 스레드가 막힌다(cx-metrics2.json tab-*). 폰에서는 더 길 것이다 [추측].
  - 결과 화면에서 움직이는 것은 제목 하나다(rbig에만 animation:pop, cx-metrics2.json result-360). 경험치·코인 숫자는 바로 찍히고, 경험치 막대는 결과 화면에 없다. 얻은 스탯은 "옷·매력 13"처럼 합계만 보이고 이번에 오른 양(+2)은 없다(9175~9177줄).
  - 홈으로 돌아와도 코인 칩 숫자가 그냥 바뀐다(1,270 → 1,314, cx-home-after-360.png). 떠오르는 +44도 없다.
  - 상점에서 물건 줄을 한 번 누르면 확인 없이 바로 산다. 라면 줄을 누르자 1,240 → 1,180이 되고 토스트 한 줄만 떴다(cx-shop-mid-360.png → cx-shop-tip-360.png, 4937~4941줄). 장비도 같다(8392~8393줄, 누르면 코인 차감과 동시에 착용).
  - 시트가 떠 있을 때 토스트가 시트 뒤로 숨는다. 토스트 z-index 40(338줄), 시트 50(482줄). 거처 시트를 띄운 채 토스트를 부르자 토스트 자리 맨 위 요소가 시트였다(cx-sheet-toast-360.png, cx-metrics2.json sheettoast-360). 시트 안 버튼이 "코인이 모자라요" 같은 토스트를 띄우면 사용자는 아무 반응도 못 본다.
- 인기 도트 게임 [관례]: 카이로소프트는 돈이 들어올 때마다 건물 위로 동전 아이콘과 숫자가 떠오르고 상단 금액이 올라가는 소리가 난다. 포켓몬은 경험치 막대가 차오르다 넘치면 레벨 업 음과 함께 능력치 표(전 → 후)가 뜬다. Stardew는 물건을 살 때 수량과 가격을 보여 주는 창을 거친다. 국내 방치형 게임(예: 『고양이와 스프』, 도트는 아님)은 보상 받기에 코인이 날아가 상단 숫자로 빨려 들어가는 연출을 쓴다.
- 고칠 방법
  - 결과 화면 순서: 제목 pop(있음) → 0.3초 뒤 경험치 막대(높이 14px, var(--g1), steps(12))가 전 값에서 새 값으로 0.8초 → 넘치면 막대 흰 깜빡임 2번 + sfx('level') + "Lv.4 → Lv.5" 줄 → 코인 숫자 0에서 목표까지 0.6초(steps(10)), 단계마다 sfx('coin') 3번까지 → 얻은 것 줄을 120ms 간격으로 하나씩(이미 있는 pop 키프레임 재사용). 스탯 줄은 "옷·매력 11 → 13 (+2)"로, +2는 var(--g3).
  - 홈 복귀 때 코인 칩 옆에 "+44"를 Galmuri11 12px var(--y1) 외곽선 글씨로 0.7초 띄우고(.pop 키프레임 재사용) 칩 숫자를 0.5초에 걸쳐 올린다.
  - 구매는 시트를 거친다: 줄을 누르면 openTip으로 그림 60×60, 이름, 효과(방 +4), 가격, 남는 코인(1,240 → 1,180)을 보여 주고 "사기"(초록 48px)와 "닫기". 라면처럼 싼 소모품만 길게 누르기로 바로 사기를 허용해도 된다.
  - 토스트 z-index를 60으로 올리거나, 시트가 열려 있으면 토스트를 시트 위쪽 가장자리 바로 위(bottom: 시트 높이 + 8px)에 띄운다. 7683줄 toast()에서 #itip이 열려 있는지 보고 위치를 잡으면 된다.
  - 탭 전환: 120ms 짧은 가로 띠 전환(#wipe를 3줄로) 또는 새 화면을 8px 아래에서 올리며 나타나기(steps(3)). 렌더가 느린 상점은 처음 한 번 그린 뒤 다시 그리지 않고 값만 갱신한다.

### C7. 지도 도트가 정수 배율이 아니다 · 중간 · P1

  - 지도 논리 폭 SW=176px를 화면 폭에 맞춰 늘린다(3832~3842줄 fitScene). 그 결과 그림 한 칸이 360에서 CSS 2.045px(기기 4.09px), 390에서 2.216px(기기 4.43px), 412에서 2.341px(기기 6.15px)다. 캔버스(704px)와 화면 기기 픽셀(720·780·1,082px)이 정수배가 아니라 몇 줄마다 한 줄씩 두꺼워진다.
  - 캐릭터 미리보기·결과·보스 끝·사건 결말의 주인공은 64px 캔버스를 160px로 그린다(459, 783, 815, 843줄). 2.5배라 도트 굵기가 2와 3으로 번갈아 나온다.
- 인기 도트 게임 [관례]: Stardew·Eastward·Sea of Stars 모두 정수 배율(픽셀 퍼펙트)로 그리고, 남는 폭은 보이는 범위를 넓히는 데 쓴다. 대표가 싫어한 "일부러 화질 낮춘 도트" 인상을 줄 수 있다 [추측].
- 고칠 방법
  - 지도: `k=Math.max(1,Math.floor(aw/176))`(360·390·412 모두 2), 캔버스 CSS 폭은 `SW*k`. 남는 폭(360에서 8px, 390에서 38px)은 두 가지 중 하나: (가) 양옆을 var(--n0)으로 비운다(작은 수정), (나) SW를 `Math.ceil(aw/k)`로 바꿔 보이는 칸을 넓힌다(360에서 180, 390에서 195. PROP 좌표가 SW를 쓰니 확인 필요, 중간 수정). RES는 기기 배율 × k의 정수로(배율 2면 4).
  - 64px 주인공: 128px(2배) 또는 192px(3배). 결과·보스 끝·사건 결말은 192px, 캐릭터 미리보기(.dprev, 높이 196px 칸)는 192px.

1. 퀘스트 화면에서 첫 보기가 보이게 한다. 높이 700px 아래에서 무대 230 → 140px, 머리 줄 69 → 48px, 보기를 아래에 붙이고 간파·막기 설명은 겹쳐 뜨는 말풍선으로. (2.7 Q1, 중간, P1)
2. 상점 즉시 구매를 막는다. 줄을 누르면 가격·효과·남는 코인이 있는 시트, "사기"를 눌러야 산다. (C4, 2.12 P1, 작음~중간, P1)
3. 토스트를 시트 위로 올린다. z-index 40 → 60 또는 시트가 열려 있으면 시트 위 가장자리에 띄운다(toast() 7683줄). (C4, 작음, P1)
4. 지도를 정수 배율로 그린다(fitScene에서 k=floor(aw/176), 남는 폭은 비우거나 SW를 넓힘). 64px 주인공 160px 표시는 128 또는 192px로. (C7, 중간, P1)
5. 글자 크기를 네 단계(10 Galmuri9, 12 Galmuri11, 15 Galmuri14, 24/30 제목)로 묶고 Galmuri14·Galmuri9 굵게를 없앤다. 허용 목록 테스트를 추가한다. (C2, 중간, P1)
6. 수집 노트와 설정에 탭이나 HUD 메뉴 단추로 들어가게 하고, 개발용 계측과 "처음부터 다시"를 사용자 화면에서 뺀다. 쓰지 않는 퀘스트 목록 화면은 지우거나 연결한다. (C6, 중간, P1)
7. 홈 HUD를 한 줄 56px로 줄이고(공·방 칩 빼기, 상태 막대는 50 아래일 때만), 지도 위 동네 이름·메인 칩을 목표 줄 하나로 합친다. 360에서 지도 +73px. (2.3 H1·H2, 중간, P1)
8. 누르는 곳을 44px 이상으로: 십자키 30 → 44px(설정에서 끄기), 이동 목록 29 → 44px, 오늘 할 일 32 → 44px, 오프닝 메뉴 42 → 48px, 출처 링크 누름 칸. (C3, 작음, P1)
9. 결과 화면 보상 연출: 경험치 막대 차오름 → 레벨 업 줄 → 코인 올라가는 숫자 → 얻은 것 줄 차례로, 스탯은 증가분 표시. 광고 버튼은 보조 모양, 돌아가기 하나만 초록. 홈 복귀 때 코인 +N 떠오름. (C4, 2.8 R1·R2, 중간, P1)
10. 스킨 v2를 도트 틀 하나로 다시 쓴다: 둥근 모서리·그라데이션·유리 효과를 빼고 3px 테두리 + .pix 모서리 + 팔레트 색으로. 해설 상자 정답·오답 띠를 되살리고, 대화창을 늘 아래·15px·이름표 방식으로 통일한다. (C1, 2.4, 중간~큼, P1)

10번은 범위가 커서, 1~9를 먼저 하고 10번은 홈·퀘스트·결과 세 화면 시안을 대표가 폰에서 본 뒤 넓히기를 권한다(회의 1003의 "작은 시안 먼저" 원칙과 같다).
