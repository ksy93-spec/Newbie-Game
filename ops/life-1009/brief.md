# 인생 모드 1단계 기획 (2026-10-09)

대표 결정:
- "미리 살아보는 인생" 모드를 만든다. 지금 방식(일반 모드)은 남겨 두되, 앞으로는 이 모드가 주가 될 것 같다.
- 시작할 때 태어남 카드를 랜덤으로 뽑는다. 다시 뽑기는 삼세판(처음 뽑기 + 다시 2번).
- 이 모드에서는 메인 장 하루 한 장 제한을 푼다. 한 인생을 2~3시간 안에 끝낸다.
- 20살 대학생부터 시작해 메인 장(첫 취업 → 전세 → 신용카드 → 차 → 결혼 → 내 집)을 지나며 나이를 먹고, 60살에 인생 결산 카드. 엔딩의 "할배는 마흔 해 뒤의 나"와 잇는다.
- 영감: "지구 80억 명 중 한 명으로 랜덤하게 태어나 실제 통계 기반으로 일생을 살아 보는 게임". 우리는 한국 20대 한 사람.

1단계 범위(지금 콘텐츠를 그대로 쓰고 흐름만 묶는다):
1. 태어남 카드: 출신 지역(수도권·광역시·그 외), 집안 형편, 성향 등 몇 칸. 실제 통계 비율로 뽑는다. 카드가 시작 코인·첫 거처·첫 대사·몇몇 수치를 바꾼다. 주인공(8명 프리셋)과 어떻게 엮을지도.
2. 나이: 장마다 나이가 오르고 HUD에 보인다.
3. 60살 인생 결산 카드: 집, 모은 돈, 지식(스탯), 큰 결정 기록, 공유 가능.
4. 큰 결정 갈림길은 2단계(대본 필요). 1단계에서는 자리만 설계.
