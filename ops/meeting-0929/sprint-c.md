# 스프린트 C (2026-09-29, CTO)

지난 회의에서 미룬 것과 QA 잔여 항목으로 범위를 잡았다. 에이전트 넷이 각자 워크트리에서 같은 파일의 다른 곳을 고친다.

| 담당 | 범위 | 완료 기준 |
|---|---|---|
| C1 콘텐츠 | 생활 이벤트를 12개에서 30개로 늘린다. 수치가 들어간 팁은 전부 출처를 확인하고, labor3(직장 내 괴롭힘 5인 미만)도 확인한다. 계절 이벤트(이사철, 연말정산, 장마·폭염 등)는 달에 맞춰 나오게 한다 | 새 이벤트 18개 이상, 출처 표, 테스트 |
| C2 첫 경험·공유 | 온보딩 직후 첫 퀘스트로 바로 안내하고 첫 이사 연출을 넣는다. 하루를 마칠 때 "내일 3개 더"를 보여 준다. 시즌 D-day 칩(연말정산, 이사철, 입사철)을 누르면 해당 체크리스트로 간다. 엔딩과 캐릭터 카드에 링크 문구를 넣는다 | 새 사용자 3분 안에 첫 보상과 이사, 테스트 |
| C3 QA 마무리 | 보스전과 고속도로 이동을 끝까지 플레이해 버그를 고친다. QA 잔여 5~8번(재배치 배너, 출석 토스트 겹침, 360×640 레이아웃, 표지판 겹침, 오프닝 잔상, willReadFrequently 경고)을 처리한다 | 두 흐름 통과, 콘솔 경고 0, 테스트 |
| C4 첫 월급 계산기 | 세전 월급을 넣으면 4대보험과 소득세(간이세액표 기준 추정)를 뺀 실수령액을 도트 영수증 카드로 보여 준다. 2026년 요율은 공식 출처로 확인하고 추정치와 기준일을 표기한다. 첫 출근 체크리스트와 연결한다 | 공개된 예시 금액 3개와 오차 1% 이내, 테스트 |
