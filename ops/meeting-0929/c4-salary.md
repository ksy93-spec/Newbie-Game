## 2. 소득세 (간이세액표 기준 추정)

연 과세급여 = (월급 - 식대) x 12 → 근로소득공제(70% / 350만+40% / 750만+15% / 1,200만+5% / 1,475만+2%, 한도 2천만) → 인적공제 150만 x 인원 → 국민연금 연 납부액 공제 → 특별공제 등 근사 → 기본세율(6~45%) → 근로소득세액공제(55%, 71.5만+30%, 한도 74만~50만~20만) → 12로 나눔, 10원 단위 절사, 지방소득세는 그 10%.

"특별공제 등" 항목은 간이세액표 산식(1명: 310만원 + 총급여의 4%, 3천만 초과분의 5% 차감, 4.5천만 초과는 1.5%, 7천만 초과는 0.5%; 2명: 360만원 기준; 3명 이상: 500만원 기준)을 쓰되, 총급여 4,500만원 이하 구간은 공개된 실수령액표에 맞도록 `450,000 + 총급여 x 7%` 로 보정했다(산식 그대로 쓰면 공개표보다 소득세가 1.5~4.5% 낮게 나옴). 4,500만원을 넘는 구간은 산식 그대로이고 cosmosfarm 월 400만원 값(166,500원)과 정확히 일치한다.

## 3. 공개 예시와 비교 (부양가족 1명, 공제 합계 오차)

|---|---|---|---|---|---|
| cosmosfarm 월급 실수령액표 | 250만 / 20만 | 255,120 | 255,690 | +570 (0.22%) | 통과 |
| cosmosfarm | 300만 / 20만 | 333,270 | 329,010 | -4,260 (-1.28%) | 초과 |
| cosmosfarm | 400만 / 20만 | 552,410 | 552,410 | 0 | 통과 |
| silsu.kr 연봉 3,000만 | 250만 / 20만 | 255,575 | 255,690 | +115 (0.04%) | 통과 |
| silsu.kr 연봉 5,000만 | 416만6,666 / 20만 | 595,135 | 592,950 | -2,185 (-0.37%) | 통과 |
| silsu.kr 연봉 1억 | 833만3,333 / 20만 | 1,802,429 | 1,773,940 | -28,489 (-1.58%) | 초과 (고소득, 사회초년생 범위 밖) |
| work.calculate.co.kr 실수령액표 | 250만 / 0 | 282,080 | 282,350 | +270 (0.10%) | 통과 |
| work.calculate.co.kr | 300만 / 0 | 373,299 | 373,950 | +651 (0.17%) | 통과 |
| work.calculate.co.kr | 400만 / 0 | 604,240 | 601,120 | -3,120 (-0.52%) | 통과 (1% 이내) |

기준은 "1% 또는 3,000원 이내". 9건 중 7건 통과, 2건 초과(300만원 cosmosfarm -4,260원, 월 833만원대). 300만원 구간은 같은 조건의 다른 표(calculate.co.kr 300만원, 식대 0)와는 +651원으로 맞아서, 공개표끼리도 300만원대 소득세가 4천원 가량 어긋난다. 간이세액표가 월급여 구간의 조회표라서 표 사이 값이 다르게 읽히는 것으로 보이며 원문 표를 열어 확인하지는 못했다. 테스트는 통과한 7건 중 6건(cosmosfarm 250·400, silsu 250·416만, calculate.co.kr 250·300)을 고정한다.

제외한 표(소득세가 간이세액표 조회값이 아니라 단순 연환산 산식으로 보이는 곳): calculkorea(월 300만 소득세 88,030), glasswallet(월 300만 89,730. 특별공제 없이 계산한 값과 89,733으로 일치), moneynestlab(월 250만 소득세 54,000), plentyer(월 250만 소득세 127,500). 이들과 비교하면 공제 합계가 3~9% 낮게 나온다. 사용자에게는 "간이세액표 기준 추정, 실제와 다를 수 있음"을 영수증에 표시한다.

## 4. 한계와 다음 확인

- 국세청 간이세액표 원문(소득세법 시행령 별표 2, 2026.2.27 개정)을 열지 못했다. 출시 전에 홈택스 간이세액표 조회로 250/300/350/400만 원 4개 값을 대조하면 보정식을 확정할 수 있다.
- 8~20세 자녀 세액공제, 중소기업 청년 소득세 감면(90%), 부녀자·한부모 추가공제는 반영하지 않는다.
- 총급여 7천만원 구간 경계에서 산식이 불연속이라 월급이 늘어도 실수령이 아주 조금 줄어드는 지점이 한 곳(월 약 604만원 근처, 약 5천원) 있다.
- 2026.7 이후 국민연금 상한(659만원)을 적용한다. 2027.1 고용보험 1.0% 인상과 2027.7 기준소득월액 조정은 확정되면 `PAY_RATES` 만 고치면 된다.
