# 뉴비 퀘스트 개인정보처리방침

[개발자 이름](이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 아래와 같이 처리방침을 공개합니다.

**1. 처리 목적과 항목**
운영자는 회원가입을 받지 않으며 이름·연락처 등을 수집하거나 서버로 전송하지 않습니다. 이용자가 입력한 나이·연차·회사 성격·권역과 게임 진행 정보는 이용자 기기 안(localStorage)에만 저장되며 운영자는 접근할 수 없습니다.
광고 게재를 위해 광고 SDK(Google AdMob)가 이용자 기기에서 다음을 자동 수집합니다: 광고 ID, 앱 세트 ID, IP 주소(대략적 위치 추정), 앱 사용·상호작용 정보(실행, 탭, 동영상 시청), 앱 성능 정보. 목적은 광고 게재, 분석, 부정 이용 방지입니다.
앱은 업데이트 확인을 위해 Expo 서버와 통신하며 IP, 앱 버전, 기기 플랫폼 정보가 전달될 수 있습니다.
문의 메일에는 이용자가 보낸 내용과 이메일 주소가 포함됩니다.

**2. 보유·이용 기간과 파기**
기기 내 정보는 앱 삭제 또는 데이터 삭제 시 즉시 삭제됩니다. 문의 메일은 처리 완료 후 [1년] 보관 뒤 삭제합니다. 광고 SDK 수집 정보는 Google 정책에 따릅니다.

**3. 제3자 제공·위탁·국외 이전**
운영자가 개인정보를 제3자에게 제공하거나 위탁하지 않습니다. 다만 Google LLC(미국)가 광고 SDK를 통해 위 정보를 직접 수집·처리하며, 이는 국외 이전에 해당합니다. 이전 방법은 네트워크 전송(TLS 암호화), 보유 기간은 Google 정책에 따릅니다. 안내: https://policies.google.com/privacy

**4. 이용자의 권리와 행사 방법**
이용자는 개인정보의 열람·정정·삭제·처리정지를 요구할 수 있습니다. 운영자가 보관하는 정보는 문의 메일뿐이며 [이메일]로 요청하면 지체 없이 처리합니다. 광고 ID는 기기 설정(설정 > Google > 광고)에서 삭제·재설정하거나 맞춤 광고를 끌 수 있습니다.

**5. 아동의 개인정보**
이 앱은 만 14세 미만 아동을 대상으로 하지 않으며 아동의 정보를 알고 수집하지 않습니다.

**6. 자동 수집 장치**
쿠키를 사용하지 않습니다. 광고 ID는 위 4항 방법으로 거부할 수 있습니다.

**7. 안전성 확보 조치**
운영자는 서버에 개인정보를 저장하지 않으며, 문의 메일은 접근을 운영자 1인으로 제한합니다.

**8. 개인정보 보호책임자·문의처**
책임자: [개발자 이름] / 이메일: [문의 이메일] / 처리 기간: 접수 후 영업일 기준 [7]일 이내.
권익침해 구제: 개인정보침해신고센터(privacy.kisa.or.kr, 118), 개인정보분쟁조정위원회(1833-6972).

**9. 시행일·변경**

## 2. Google Play Data safety 답변 초안
근거: AdMob 공식 문서(Google Play data disclosure, 2026-09-28 갱신본 기준). Google은 이 SDK 수집 데이터가 광고·분석·부정 방지 목적으로 기본 수집·공유되며 TLS로 암호화된다고 밝힌다. 최종 책임은 개발자에게 있다.
- 데이터 수집 여부: 예 (SDK 수집 포함)
- 대략적 위치(IP 기반): 수집·공유, 필수, 목적 광고/분석/부정 방지
- 앱 활동(앱 상호작용): 수집·공유, 필수
- 기기 또는 기타 ID(광고 ID, 앱 세트 ID): 수집·공유, 필수
- 앱 정보 및 성능(진단): 수집·공유, 필수
- 개인정보(이름·이메일 등), 금융, 사진: 앱 자체는 수집 안 함. 사진은 기기 안 처리라 "수집" 아님(Play 도움말 기준 확인 필요)
- 전송 중 암호화: 예
- 삭제 요청 수단: 앱은 계정·서버 저장이 없다. 답변 방식은 Play Console 도움말 재확인 필요
- 개인정보처리방침 URL 필수 입력, 광고 포함 앱 표시 체크
- 타 SDK 추가 시(분석, 크래시 리포트) 재작성. 타깃 연령은 18세 이상 선택 시 가족 정책 회피 여부 확인 필요

## 3. FAQ 10개
1. 진행을 초기화하려면? 앱 내 [설정 메뉴 위치 기재] 또는 기기 설정 > 앱 > 저장공간 > 데이터 삭제. 되돌릴 수 없다.
2. 기기를 바꾸면 진행은? 저장이 기기 안에만 있어 이전할 수 없다. 새 기기에서는 처음부터 시작한다.
3. 앱을 지우거나 데이터를 삭제하면? 진행이 삭제된다. 서버 백업이 없어 복구할 수 없다.
4. 광고는 꼭 봐야 하나? [기획 확인 후 기재: 보상형 광고는 선택 시청, 보상은 게임 내 아이템뿐].
5. 광고가 안 나오거나 보상이 안 들어옵니다. 네트워크 확인 후 앱 재실행. 계속되면 기기 모델·안드로이드 버전을 보내 달라.
6. 맞춤 광고를 끌 수 있나? 설정 > Google > 광고에서 광고 ID 삭제 또는 맞춤 광고 해제.
7. 어떤 정보를 수집하나? 회원가입이 없고 입력 정보는 기기 안에만 저장. 광고 SDK가 광고 ID 등을 수집한다(처리방침 링크).
8. 정보가 틀렸어요. 문항 화면의 신고 버튼 또는 [이메일]로 문항, 틀린 내용, 근거 링크를 보내 달라. 4번 절차로 처리한다.
9. 기준일이 지난 정보는 믿어도 되나? 제도는 바뀐다. 화면의 기준일과 원문 링크를 확인해야 한다.
10. 법률·세무 상담을 대신하나? 아니다. 정보 제공이며 계약·세금 판단은 전문가·해당 기관에 확인한다.

- 저장 날아감: 죄송합니다. 진행은 기기 안에만 저장되어 앱 삭제·데이터 삭제·기기 변경 시 복구할 수 없습니다. 발생 상황을 알려 주시면 원인을 확인하겠습니다.
- 기타: 의견 감사합니다. 자세한 사항은 [이메일]로 남겨 주시면 확인해 답하겠습니다.

## 4. 정보 오류 신고 → 수정 절차
1. 접수: 이메일, 리뷰, 신고 버튼. 접수 로그(날짜, 문항 ID, 내용, 출처)를 기록하고 영업일 3일 내 접수 회신.
2. 등급: A 금전 피해 가능(전세·청약·세금·4대보험), B 수치·문구 오류, C 표현·오탈자.
3. 검증: 정부·공공기관 원문(1차 출처)으로만 확인한다. 신고자 링크만으로 수정하지 않는다. 확인 불가 시 "확인 중" 표기.
4. 조치: A는 48시간 내 해당 문항 비공개 또는 문구 임시 수정 후 정식 수정. B는 7일, C는 다음 정기 배포.
5. 수정: 데이터 수정 + 출처 링크 + 기준일 갱신(확인일이 아닌 제도 적용 기준일)을 함께 바꾼다. 변경 이력에 문항 ID·사유·날짜를 남긴다.
6. 배포: expo-updates OTA 가능 여부와 스토어 심사가 필요한 변경을 구분한다.
7. 회신: 신고자에게 결과를 알린다. 반영 불가 시 사유와 근거를 적는다.
8. 정기 점검: 분기 1회 전 문항의 기준일·링크 유효성 점검, 연초·제도 개정 시 임시 점검.
