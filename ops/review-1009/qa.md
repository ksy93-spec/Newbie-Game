대상: prototype/newbie-quest-demo.html (커밋 b99c242). 코드는 고치지 않았다.
방법: Playwright, 360×640과 390×844(2배, 터치). 저장 없이 `#nointro` 없이 오프닝 메뉴부터 실제로 눌렀다. 컷신은 캔버스를 탭해서 넘기고, 보기 장면만 `MQP.pick`을 썼다. 대화 상자도 탭으로 닫았다.
스크립트: ops/review-1009/tools/lib.mjs(공용), qa-a-start.mjs(처음 켬 → 카드 → 태어남 → 첫 대화), qa-b-*.mjs(뒤에 덧붙임). 그림: ops/review-1009/img/qa-{s=360|m=390}-*.png.

## 1차 결과 (오프닝 → 카드 → 태어남 → 첫 대화)

잘 되는 것: 오프닝 메뉴 세 칸(인생 모드 추천 · 일반 모드 · 소리)이 두 크기 모두 화면 안에 들어오고 눌린다. "이 인생으로 살기"(#obnext)는 두 크기 모두 덮이지 않고 바로 눌린다(지난번 고친 것 확인). 다시 태어나기 두 번 뒤 버튼이 "마지막 카드예요"로 바뀌고 잠긴다. 주인공 고르기 화면 없이 바로 태어남 컷신으로 간다. 태어남 컷신 9장면을 탭 24번으로 넘겼다. 홈 HUD "20살 · Lv.1". 콘솔·페이지 오류 0건. 가로 넘침 0건.

### Q1. 자취 카드: 카드·게임은 "고시원", 태어남 컷신은 "자취방" — 중간
- 재현: 새로 켬 → 인생 모드 → 형편 보통·거처 자취 카드가 나올 때까지 진행(390: 윤지훈 강원 춘천 고졸 자취, 360: 손지은 경기 평택 전문대 자취) → 이 인생으로 살기 → 태어남 컷신 마지막 장면.
- 보이는 것: 마지막 장면 "스무 살 봄. 자취방에서 인생이 시작됐다." 그런데 홈 아래 줄은 "고시원 · 다음 거처까지 집 스탯 20", 방도 고시원이다(qa-s-05home.png).
- 원인: `lifeFx`의 `home`은 자취면 `TIERS_ORIG[tier].name`(고시원/원룸 월세), `lifeFillVals().home`은 `LIFE_FX.living[p.living].home`('자취방')을 따로 쓴다.
- 고칠 것: `lifeFillVals`의 `home`을 `lifeFx(p).home`으로 맞춘다.

### Q2. 자취 카드에게 부동산 사장이 "독립은 아직이어도" — 중간
- 재현: Q1과 같은 자취 카드로 홈에 도착 → 첫 대화(intro)를 끝까지 탭.
- 보이는 것: 마지막 줄 "독립은 아직이어도 집 공부는 지금부터야. 첫 상담은 오른쪽 끝 부동산에서 받아 봐." 이 사람은 이미 고시원에서 혼자 산다.
- 고칠 것: `TUT_STEPS` intro의 `life` 마지막 줄을 `lifeNest()`일 때만 쓰고, 자취면 "혼자 살아 보니 방값이 만만찮지? 첫 상담은 오른쪽 끝 부동산에서 받아 봐."로 바꾼다.

### Q3. 수도권 자취 카드에게 할배가 "집이 가까운 게 큰 밑천이야. 아낀 월세는 모으게." — 중간
- 재현: 360 실행, 손지은(경기 평택 · 수도권 · 자취) → 태어남 컷신 5번째 장면.
- 자취라서 월세를 낸다. 대사 갈래가 출신 지역(cap)만 보고 거처를 안 본다.
- 고칠 것: `lifeBirthScenes`의 할배 둘째 줄을 region이 아니라 `p.living==='본가'`로 고른다. 자취면 "혼자 사는 첫해가 제일 비싸네. 방값부터 적어 두게."

### Q4. 강원 춘천시 퇴계동이 "산 너머 버스가 하루 네 번 서는 마을" — 낮음
- 재현: 390 실행, 윤지훈(강원 춘천시 퇴계동, 그 외) → 태어남 컷신 3·5번째 장면.
- 춘천은 시내 동이다. band '그 외' 전체에 산골 대사가 붙는다.
- 고칠 것: `LIFE_HOMETOWN.etc`를 "버스 배차가 30분인 동네." 정도로 낮추거나, 시(市)이면 "도청 소재지라도 서울은 멀다."로 나눈다.

### Q5. 카드 아래 "다시 태어나기" 버튼이 첫 화면에서 안 보인다 — 낮음
- 재현: 360×640 · 390×844 모두 카드 첫 화면(qa-s-02card.png). 버튼 중심이 y=900으로 화면 밖이고, 390에서는 스크롤 중간에 고정 "이 인생으로 살기" 아래에 깔린다(hitTest: covered by #obnext).
- 스크롤하면 누를 수 있어서 막힘은 아니다. 다만 "삼세판"을 모르고 첫 카드로 시작하기 쉽다.
- 고칠 것: `birthRender`에서 다시 태어나기 버튼을 카드 위(합계 줄 바로 아래)나 #obnext 옆 보조 버튼으로 옮긴다.

## 2차 결과 (첫 퀘스트들)

잘 되는 것: 오늘 할 일 → "다음 퀘스트로 가기"를 누르면 걸어가서 창구가 열리고, 보기를 눌러 퀘스트 두 개를 끝냈다(두 크기 모두). 첫 퀘스트 뒤 할배 컷신 8장면도 "본가 방이 있을 때 집 공부를 해 두게"로 카드와 맞는다. 퀘스트 화면 넘침 없음. 콘솔 오류 없음.

### Q6. 퀘스트 두 개 뒤 "다음 퀘스트로 가기"가 사라지고, 메인 칩은 토스트만 띄운다 — 높음
- 재현(360·390 같음, 본가 · 대학생 카드): 새로 켬 → 인생 모드 → 이 인생으로 살기 → 대화 닫기 → 오늘 할 일 → 다음 퀘스트로 가기 → 퀘스트 끝 → 한 번 더 → 세 번째로 오늘 할 일을 연다.
- 보이는 것: 시트에 "광고 보고 하나 더 열기 · 오늘 2회 남음", "광고 보고 출석 보너스", "닫기"뿐이다. 홈 위 칩 "다음 메인 1장 첫 취업 · 퀘스트 1개 더"를 누르면 토스트 "1장 첫 취업 · 퀘스트 1개 더"만 뜬다(qa-m-09after2.png).
- 실제로는 열린 퀘스트가 다섯 개 있다(stu1 카페, stu2·stu3 학교 앞, job1 고용센터, job3). 전부 동네 밖 지도라 `guideReach`가 false다. `guideNext`는 동네에서 바로 닿는 퀘스트만 고른다. 지도(#hmini)를 열면 "학교 앞 · 할 일 6"이 보이니 막힘은 아니지만, 처음 하는 사람은 광고 버튼만 보고 멈춘다. 인생 모드는 퀘스트 세 개가 한 살이라 이 벽이 20살에 바로 온다.
- 고칠 것: `guideTarget`이 null이고 동네 밖에 열린 퀘스트가 있으면 오늘 할 일에 "학교 앞으로 가기 · 할 일 6"(지도 이동 `travelTo(mk)`)을 넣는다. `mqChip`의 wait 탭도 `guideTarget()||가까운 지도`로 보내고, 토스트는 "학교 앞에 퀘스트가 있어요"로 바꾼다. 인생 모드에서는 "광고 보고 하나 더 열기"를 빼거나 맨 아래로 내린다(이미 다섯 개가 열려 있어 의미가 없다).

## 3차 결과 (나이 → 1~3장 → 이사 → 캐릭터·상점 → 새로고침 → 두 칸 오가기 → 예순 → 다시 태어나기 → 앨범)

스크립트: qa-e-chapters.mjs, qa-f-modes.mjs(두 크기 모두 같은 결과). 세 번째 퀘스트는 `S.done`에 열린 퀘스트 id를 넣어 채웠고(지도 이동은 Q6에서 탭으로 확인), 집 스탯을 90으로 올려 원룸 전세를 열었다. 2장 마지막 결과 화면(epend)은 운전기가 못 눌러서 `S.mq.done.lease`를 넣었다. 예순은 메인 여섯 장을 done으로 넣고 `lifeEnd()`를 불렀다. 그 밖에는 모두 탭.

잘 되는 것(막힘 없음):
- 퀘스트 셋 → "21살이 됐어요" 토스트, 칩 "메인 1장 첫 취업 · 눌러서 시작". 칩 탭 → 세월 컷신 y24(전문대 갈래 "전문대를 마친 지 두 해") → 할배 → 1장 본편(보기 4번) → "1장 클리어" 시트. 나이 24, 신분 직장인.
- 2장: 할배 안내 → 세월 y26 "스물여섯. 본가 방 생활도 몇 해째다" + "아낀 방값 ￦40" → 부동산 → 매물 집 → 부동산 → 매물 집 → 주민센터까지 칩 탭만으로 갔다. 이사는 본가 방 → 원룸 전세로 됐다.
- 3장: y27 → 3장 본편(보기 4번) → "3장 클리어". 나이 27.
- 새로고침: 메뉴 "이어하기 · 인생 / 이름 · 27살 · 직장인 · 메인 3/6", 들어가면 상태 차이 0.
- 두 칸: 인생 진행 중에 "일반 모드"로 새로 시작 → 일반 칸은 노숙·Lv.1·`S.life` 없음, `TIERS[0]`이 "노숙"으로 돌아온다. 메뉴에 "이어하기 · 인생"과 "이어하기 · 일반"이 같이 뜨고, 오가도 서로 값이 섞이지 않는다(인생: 본가 방·원룸 전세·Lv.7·￦3210 / 일반: 노숙·Lv.1·￦180). 저장 칸 nq.v8 · nq.life.v1 · nq.slot.
- 예순: y60 8장면 → 결산 카드(넘침 없음, "계속" 눌림) → 마지막 컷신 12장면 → 공유 · 다시 태어나기 · 닫기. 다시 태어나기 → 새 카드(남은 2번) → "이 인생으로 살기" 눌림. 메뉴에 "인생 앨범 · 1번의 인생", 열면 "티끌 태산 / 이름 · 출생지 · 원룸 전세 · 날짜".
- 콘솔·페이지 오류: 모든 실행에서 0건. 가로 넘침: 메뉴·카드·홈·퀘스트·캐릭터·상점·결산·앨범 모두 0건.

### Q7. 1장을 마친 직후 HUD 아래 줄이 "취준생 · 준비 6개월 미만" — 중간
- 재현: 위 흐름에서 1장 본편 끝 → "1장 클리어" 시트를 닫는다. `S.status`는 '직장인'인데 #hsub는 "취준생 · 준비 6개월 미만 · 광역시"로 남는다. 다음 갱신(상점 갔다 오기 등)에야 "직장인 · 1년 미만"이 된다.
- 원인: `lifeTick`이 mqDone('job')을 보고 직장인으로 바꾸지만, 장 완료 시트 뒤 `hudRefresh`가 그보다 먼저 돈다. 또 `S.prep='공채'`(글자)라 `whyLine`이 "준비 6개월 미만"으로 읽는다(지난 QA 2-3 그대로).
- 고칠 것: 장 완료 처리(`mqFinish` 쪽) 끝에서 `lifeTick(); hudRefresh();`. `birthApply`와 `lifeTick`의 `S.prep='공채'`를 `S.prep=0`으로.

### Q8. 세월 컷신 뒤 1장 본편 내내 HUD가 "21살" — 낮음
- 재현: 21살에 1장 칩 탭 → y24 컷신을 넘긴다. `S.life.age`는 24인데 HUD #hnm은 장을 마칠 때까지 "21살 · Lv.2".
- 고칠 것: `lifeBeforeCh`에서 `lifeTick()` 다음에 `hudRefresh()`.

### Q9. 일반 모드를 새로 고르면 온보딩 동안 HUD에 인생 칸 값("27살 · Lv.7 / 직장인 · 1~3년차")이 남는다 — 낮음
- 재현: 인생 진행 중 → 새로고침 → 메뉴 "일반 모드". `S`는 Lv.1·노숙인데 #hnm·#hsub는 인생 칸 글자 그대로. 홈에 들어가면 "대학생 Lv.1"로 바뀐다. 온보딩 화면에서 HUD가 가려져 있으면 보이지 않을 수 있다(qa-*-18normalOb.png).
- 고칠 것: 메뉴 `pick('new')`/`pick('wipe')`에서 `S=fresh()` 뒤 `hudRefresh()`. `switchSlot`도 온보딩 갈래에서 `hudRefresh()`.

### Q10. 본가에서 1장 뒤 원룸 전세가 열려도 캐릭터 탭에 이사 버튼이 없다 — 중간(확인 필요)
- 재현: 본가 카드, 1장 클리어 → 집 스탯이 올라 원룸 전세(7)가 열림 → 캐릭터 탭. 거처 칸은 "본가 방 방어 +16" 하나뿐, "이사/옮기기" 글자 버튼 없음(qa-*-13char.png). 결국 2장 전세 계약을 끝내야 본가를 나온다.
- 본가 → 고시원·원룸 월세로 먼저 나가는 길이 화면에 없다. 거처 칸을 눌렀을 때 목록이 뜨는지는 이번에 못 눌러 봤다.
- 고칠 것: 기획 확인. 2장이 독립의 순간이라면 거처 칸 아래에 "본가에서 지내는 중 · 2장 전세 계약으로 독립"을 적는다. 아니라면 `tierGrow`가 연 칸으로 옮기는 버튼을 거처 칸에 둔다.

### Q11. 상점 세간 잠금 글이 아직 "고시원부터 / 반지하부터", 매트 설명 "바닥에서 자도" — 중간 (지난 QA 1-7 그대로)
- 재현: 본가 카드로 상점 탭(qa-*-14shop.png). "접이식 책상 … 고시원부터", "소형 냉장고 … 반지하부터", "접이식 침대 … 반지하부터". 인생 모드는 1~3칸을 건너뛰는데 잠금 글은 일반 사다리 이름이다.
- 고칠 것: 잠금 글을 인생 모드에서 `TIERS[nextTierIdx 기준]` 이름으로, 매트 설명은 `lifeNest()`이면 "본가 방 바닥에 깔아 두는 손님용 매트."로.

### Q12. 광역시 본가 카드에게 마지막 컷신 "막 상경한 누군가" — 낮음
- 재현: 390 실행, 정성민(부산 · 본가, 한 번도 이사 안 가고 부산 원룸 전세) → 예순 → 계속 → 마지막 컷신 8번째 장면 "언젠가 막 상경한 누군가를 만나면". `LIFE_START.metro='상경한'`이 출신만 본다.
- 고칠 것: `lifeFillVals().start`를 `p.living==='본가'||p.band==='수도권' ? '독립한' : '상경한'`으로.

### Q13. 마지막 컷신의 복선 "허허, 그 얼굴 보니 딱 옛날 생각이 나는구먼"을 받을 앞 장면이 없다 — 낮음 (지난 QA 3-4 그대로)
- 재현: 인생 모드 처음 켬 → 태어남 컷신 할배 첫 줄은 "허허, 카드 한 장 받았구먼."(부산 방언판 "카드 받았나? 어디 함 보자"). 예순 마지막 컷신 11번째 장면이 이 말을 되받는데 인생 모드 사람은 원래 줄을 본 적이 없다. 메뉴의 "프롤로그 다시 보기"도 인생 칸에서 일반 프롤로그를 튼다.
