## 1. 문구 감사 (어조·일관성·카드와의 모순)

### 1-1. 꼭 고칠 모순 (대표가 다시 해 보면 바로 보이는 것)

**A. 비수도권 시내 출신에게 "산 너머 버스 하루 네 번 마을"** (30%의 카드)
"그 외" 띠에 들어간 주소는 천안 불당동, 창원 상남동, 청주 복대동, 전주 효자동, 제주 노형동처럼 전부 시내 "동"이다. 그런데 태어남 컷신, 할배 대사, 앨범 컷신(CS_STORY memory)이 모두 시골 마을을 전제한다. 카드에 "충남 천안시 서북구 불당동 출생"이라 써 놓고 바로 "산 너머 버스가 하루 네 번 서는 마을"이 나온다. 지역 비하로 읽힐 수도 있다(3절).
- 찾을 글자 `etc:   { bg: 'hometown', cast: [['hero', 'C']],` 다음 줄
  - 앞 `text: ['산 너머 버스가', '하루 네 번 서는', '마을.'] } },`
  - 뒤 `text: ['서울까지는', '고속버스로 몇 시간.', '여기가 내 동네다.'] } },`
- 찾을 글자 `etc:   { bg: 'town', cast: [['hero', 'L'], ['halbae', 'R']], who: '귀인 할배',` 다음 줄
  - 앞 `text: ['...하루 네 번 버스라.', '허허, 잘 알지.', '아주 잘 알아.'] } },`
  - 뒤 `text: ['...서울까지 몇 시간이라.', '허허, 잘 알지.', '아주 잘 알아.'] } },`
- 시골 마을 그림(hometown 배경)을 살리고 싶으면, LIFE_SIDO "그 외" 시도마다 읍·면을 하나씩 넣고(예: 충남 `['예산군',['예산읍','삽교읍']]`, 경북 `['의성군',['의성읍']]`, 전남 `['해남군',['해남읍']]`, 강원 `['정선군',['정선읍']]`) 주소가 읍·면으로 끝날 때만 지금 대사를 쓴다(lifeBirthScenes에서 `/[읍면]$/.test(card.dong)`로 고른다).
- CS_STORY memory("...어? 우리 동네도 버스가 하루 네 번인데.")도 같은 조건으로 묶는다. 찾을 글자 `(!lifeOn()||(S.life.prof&&S.life.prof.band==='그 외'))` → `(!lifeOn()||(S.life.prof&&/[읍면]$/.test(S.life.prof.dong)))`. 읍·면을 안 넣는다면 memory 컷신은 인생 모드에서 빼는 편이 낫다.
- 같은 이유로 지역 글자 `regionText:p.band==='그 외'?'지방 소도시'`의 "소도시"도 창원(100만)·청주(85만)에 맞지 않는다 → `'비수도권 도시'`.

**B. 카드의 첫 거처와 컷신의 {home}이 다르다** (자취 37%)
카드는 lifeFx가 정한 "첫 거처 고시원 / 원룸 월세"를 보여 주는데, 컷신 {home}은 LIFE_FX.living의 '자취방'을 쓴다. 카드에서 고시원을 확인한 사람이 "스무 살 봄. 자취방에서 인생이 시작됐다."를 본다.
- 함수 lifeFillVals, 찾을 글자 `home:p.living?LIFE_FX.living[p.living].home:'방',`
  - 뒤 `home:p.living?lifeFx(p).home:'방',`

**C. 수도권 자취·기숙사에게 "아낀 월세는 모으게"** (22%)
- 찾을 글자 `text: ['집이 가까운 게', '큰 밑천이야.', '아낀 월세는 모으게.'] } },`
  - 뒤 `text: ['일자리가 가까운 게', '큰 밑천이야.', '오가는 시간도 돈이네.'] } },`

**D. 튜토리얼 첫 대사: 자취·기숙사인데 "독립은 아직이어도", 처음 온 동네인데 "오가며 얼굴은 봤지?"**
TUT_STEPS intro의 `life` 줄은 본가 사람만 전제한다. 자취·기숙사는 46%다.
- 찾을 글자 `life:['안녕, 이 동네에서 부동산 하는 사람이야. 오가며 얼굴은 봤지?',`
  - 뒤 `life:['안녕, 이 동네에서 부동산 하는 사람이야. 앞으로 자주 보겠네.',`
- 찾을 글자 `'독립은 아직이어도 집 공부는 지금부터야. 첫 상담은 오른쪽 끝 부동산에서 받아 봐.'],`
  - 뒤 `'어디서 지내든 집 공부는 지금부터야. 첫 상담은 오른쪽 끝 부동산에서 받아 봐.'],`

**E. 조사 오류 "기숙사이 있을 때"** (기숙사 시작 전원, 첫 퀘스트 컷신)
- 찾을 글자 `TIERS[S.tier].name+'이 있을 때'`
  - 뒤 `TIERS[S.tier].name+(/[사]$/.test(TIERS[S.tier].name)?'가':'이')+' 있을 때'` (본가 방→"방이", 기숙사→"기숙사가". 받침 판정 함수가 파일에 없으니 이 두 이름만 다루면 된다)

**F. 졸업 뒤에도 기숙사** (기숙사 시작 18.7%)
대학생→취준생이 되어도 거처는 "기숙사" 그대로이고, 스물여섯 세월 컷신은 "기숙사 생활도 몇 해째다"라고 한다.
- 함수 lifeBeforeCh, 찾을 글자 `if(id==='lease'&&lifeNest()) sc[0].text=['스물여섯.',TIERS[S.tier].name+' 생활도','몇 해째다.'];`
  - 뒤 `if(id==='lease'&&lifeNest()) sc[0].text=lifeLiving()==='기숙사'?['스물여섯.','기숙사를 나온 짐이','아직 박스째다.']:['스물여섯.','본가 방 생활도','몇 해째다.'];`
- 함수 lifeTick의 졸업 토스트 `toast('졸업했어요 · 이제 취준생')` → 기숙사일 때 `toast(lifeNest()&&lifeLiving()==='기숙사'?'졸업했어요 · 기숙사도 곧 비워야 해요':'졸업했어요 · 이제 취준생')`

**G. 캐릭터 화면 "준비 undefined"** (고졸 시작 25% + 졸업 뒤 전원)
인생 모드는 S.prep에 문자 '공채'를 넣는데, 화면은 숫자 칸으로 읽는다. HUD 둘째 줄에서는 "상황"이 빠지고(`취준생 · 수도권`), 캐릭터 화면 상황 칸은 `준비 undefined`가 된다.
- 함수 birthApply 찾을 글자 `S.prep=(fx.status==='취준생')?'공채':null;` → `S.prep=(fx.status==='취준생')?0:null;`
- 함수 lifeTick 찾을 글자 `S.status='취준생'; S.prep='공채';` → `S.status='취준생'; S.prep=0;`
- (fits 등에서 '공채' 글자를 쓰는 곳이 없는지 개발이 한 번 확인)

**H. 할배 정체와 맞지 않는 줄** (엔딩 반전 "나는... 마흔 해 뒤의 자네라네")
할배가 미래의 나라면 할배 카드는 곧 내 카드다. 그런데 "낯이 익구먼"은 비수도권+빠듯에게만 나오고, 엔딩은 "내 카드보다 훨씬 낫구먼"이라고 한다.
- 찾을 글자 `text: ['{title}.', '...내 카드보다', '훨씬 낫구먼.'] },`
  - 뒤 `text: ['{title}.', '...내가 살았던 것보다', '훨씬 낫구먼.'] },`
- `same` 장면(`'...이 카드는', '어째 낯이 익구먼.'`)은 모든 카드에 넣고(lifeBirthScenes에서 조건 없이 push), MBTI/음식 장면은 그 뒤에 그대로 둔다. 복선이 모든 판에 깔린다.

**I. 결산 서랍 종이가 모두에게 같다**
LIFE_END part1 doc의 `['스물여섯', '전세 계약서']`, `['서른일곱', '등기권리증']`은 집을 못 산 사람(칭호 "가벼운 발걸음: 큰 집은 없어도")에게도 나온다.
- 함수 lifeEnd에서 `lifeFill(LIFE_END.part1,f)` 전에, 자가가 아니면 마지막 줄을 바꾼다: `['서른일곱', '등기권리증']` → `['서른일곱', '전세 계약서(세 번째)']`.
- 같은 맥락으로 세월 y37 `'전세 만기를', '세 번째 맞는다.'`는 이미 자가인 사람에게 어긋난다. TIERS[S.tier].own이면 `['서른일곱.', '이번엔 집을', '넓혀 볼까 한다.']`.
- 세월 y26 `'이번엔 전세로', '가 볼까?'`는 이미 전세(TIERS 7칸 이상)면 `'이번엔 투룸으로', '가 볼까?'`.

**J. MBTI 장면이 한 번도 안 나온다** (죽은 대사)
lifeBirthScenes의 고르는 식 `(card.birth || '').length % 2`는 생일 글자가 늘 10자("2006.03.20")라 언제나 0이다. 음식이 비는 카드가 없으니 MBTI E/I 장면은 영영 안 나온다(30장 모두 음식 장면).
- 찾을 글자 `(!card.food || (card.birth || '').length % 2)` → `(!card.food || +(card.birth || '0').slice(-1) % 2)`

**학교 이름.** "중고"는 이제 안 나온다. 대신 동 이름을 그대로 붙여 어색하거나 웃기게 읽히는 이름이 나온다(2만 장에서 확인): **정자고, 정자공업고, 주례고, 사직고, 석사공업고, 하단고, 무거고, 왕조고, 내외고, 내외외고, 내외마이스터고, 수송상업고, 가정고, 가정예고, 온천고, 온천외고, 상인고, 비전외고, 망원디자인고**. 또 동 이름+외고/예고/마이스터고는 "대치외고"처럼 실제처럼 들리는 가짜 명문고를 만든다.
- 함수 lifeGen, 찾을 글자 `var hn=(stem.length>=2&&rp()<0.5)?stem:upick(rp,T.hsPool);`

## 3. 공정성·민감도

**지역.**
- 카드와 HUD의 "그 외"는 비수도권 사람을 "나머지"로 부른다. 카드·HUD 표시는 "비수도권"으로(1-2). 내부 값 '그 외'는 일반 모드 퀘스트 필터(f.regions)가 쓰므로 바꾸지 말고, 보이는 글자만 바꾼다.
- 비수도권 전체를 "버스 하루 네 번 마을"로 그리는 것은 고정관념이다(1-1 A). 실제 주소와 맞을 때만 쓴다.
- 사투리: 할배가 고향 말씨로 말을 걸었다가 표준어로 고치는 연출은 놀림 없이 가볍다. 카드 한마디 중 경상 `'마, 일단 해 보는 기다.'`의 "마,"는 거칠게 읽힐 수 있다 → `'일단 해 보는 기라.'`. 전라 `'오늘도 무사히 넘어가믄 된당께.'`는 그대로 좋다.
- 비수도권 보정(코인 +20, 집 +10)은 카드에 숫자로 보이는데, 이유를 모르면 "지방이라 동정받는다"로 읽힐 수 있다. 카드 작은 글자에 이유를 보탤 수 있다: `fxText(b)` 뒤에 그 외일 때 `' · 지역 집 퀘스트 보정'`(선택).

**다문화.**
- "엄마가 베트남 출신"은 사실만 적어 무난하다. 더 따뜻하게는 `'엄마 고향은 베트남'`, `'아빠 고향은 다른 나라'` 꼴을 권한다. 찾을 글자 `multi:[{v:'엄마가 베트남 출신',p:30},` 줄 전체를 `{v:'엄마 고향은 베트남'}` 꼴로.
- "아빠가 다른 나라 출신"만 나라가 없다. 다른 칸과 같은 무게가 되도록 나라를 적거나(`'아빠 고향은 미국'` 등), 엄마 쪽도 모두 "다른 나라"로 묶는다.
- 가족 칸과 어긋나지 않게(아빠와 나 + 엄마 쪽 다문화) lifeGen에서 parents가 '아빠와 나'면 엄마 쪽을, '엄마와 나'면 아빠 쪽을 고르지 않는다.
- 다문화는 스탯·코인에 닿지 않는다. 좋다. 이대로 유지.

**한부모·조손·재혼.**
- "엄마와 나", "아빠와 나"는 중립적이고 좋다.
- `'새 가족(재혼 가정)'` → `'엄마·아빠(재혼 가족)'`보다는 설명 없는 `'새로 꾸린 가족'`을 권한다. 괄호 속 분류어가 카드에서 꼬리표처럼 보인다.
- `'조부모님과'` → `'할머니·할아버지와'`.
- 두 부모를 전제하는 문구가 있다: 음식 "엄마표 김밥"(→ '집 김밥'), 그리고 y24 대안 줄을 쓸 때 "엄마가"(→ 가족 칸 보고 '가족이'). 형편 '빠듯'과 한부모가 겹칠 때 할배 대사가 "빠듯하게 자라면 ... 그게 자네 무기야"로 가난을 미화하는 쪽으로 읽힐 수 있다 → `['빠듯한 집에서 컸으면', '숫자에 밝지.', '그건 자네 힘이야.']`.
- 칭호 bloom `'출발은 늦었지만'`은 형편을 "늦음"으로 부른다 → `'출발선은 뒤였지만'`.

**몸.**
- 카드에 "키 159cm · 듬직한 편"이 큰 글자로 나온다. 여성에게 "듬직한 편", 남녀 공용의 "다부진 편"은 체형 평가로 읽힌다. 게임 수치에 아무 영향이 없으니 **체형 칸은 빼는 것**을 1안으로 권한다(찾을 글자 `tmi('키',p.height+'cm · '+p.build)` → `tmi('키',p.height+'cm')`).
- 남기려면 평가가 없는 말로: `build:[{v:'마른 편'},{v:'보통'},{v:'다부진 편'},{v:'듬직한 편'}]` → `'호리호리', '보통', '탄탄', '큰 체격'`, 그리고 남녀 표를 나눈다(2-3).
- 안경 "씀/안 씀"은 무난하다.
