# 스프라이트 도구

손으로 그린 원화에서 `assets/sprites/*.png`가 나오기까지의 과정을 남겨 둔 곳.

- `extract-layers.py` · `cutout.py` — 플레이어 아바타를 레이어 다섯 장으로 쪼갠다 (아래 1~5)
- `cut-cast.py` — 한 장에 여럿 그려진 원화에서 NPC와 펫을 잘라낸다 (아래 조연)

## 플레이어 아바타

원본 일러스트 한 장에서 `assets/sprites/img{M,F}_*.png` 다섯 장이 나오기까지 순서:

1. **배경 제거** — 굵은 검은 외곽선을 연결 요소로 잡고, 테두리에서 flood fill 해 바깥을 지운 뒤
   구멍을 메운다. 64px 격자로 내리고 색 수를 22개로 줄인다.
2. **레이어 분리** — 정수리에서 flood fill 해 머리카락을 뜯어내고(눈·눈썹은 보호),
   몸통 박스 안에서 남색 계열과 그에 붙은 외곽선을 상의로, 엉덩이 아래를 하의로 가른다.
3. **소품 제거** — 커피 텀블러와 서류가방을 지운다. 소품이 겸하고 있던 외곽선까지 사라지므로,
   드러난 밝은 가장자리에 1px을 다시 찍는다. 이웃이 하나뿐인 픽셀은 가시가 되므로 걸러낸다.
4. **왼팔 복원** — 커피를 지우면 왼팔이 같이 날아간다. 오른팔 영역을 좌우 반전해 왼쪽에 이식하고
   2px 안쪽으로 당겨 몸에 붙인다.
5. **다리 골 파기** — 원본은 두 다리가 붙어 있고 허벅지 쪽 골이 거의 없다. 한 덩어리로 보여서
   한쪽 다리가 뜯겨 나간 것처럼 읽힌다. 줄마다 가운데에서 가장 어두운 칸을 찾아 무릎 위까지 골을 판다.
   이미 골이 파여 있으면 건드리지 않는다.

각 단계마다 눈으로 확인해야 한다. 자동화만 믿으면 얼굴에 멍이 들거나 팔이 사라진다.

## 조연 (`cut-cast.py`)

일곱을 한 장에 그린 원화에서 각자를 떼어낸다. 배경이 밝은 벽과 어두운 건물 두 가지라
채우기 한 번으로는 안 된다. 외곽선 바깥만 채우는 방법은 할머니의 흰머리를 지키지만 건물을 남기고,
같은 색을 따라가는 방법은 건물을 떼어내지만 흰머리를 먹는다. 둘을 교차시킨다.

주의할 것 둘:

- **상자를 넉넉히 잡는다.** 상자 변이 인물을 스치면 그 변에서 시작한 채우기가 몸 안으로 흘러든다.
  처음엔 할아버지의 지팡이와 왼팔, 남자아이의 종이비행기가 통째로 사라졌다.
- **몸에 둘러싸인 배경 조각은 따로 지운다.** 테두리에서 닿지 않으니 채우기로는 안 지워지고,
  구멍 메우기가 오히려 굳혀 버린다. 건물 색을 직접 지정해 한 번 더 지운다.

잘라낸 뒤 목표 높이로 줄이면 나오는 폭·높이를 `src/sprite/cast.ts`의 `w`, `h`에 그대로 적는다.
숫자가 틀리면 그림이 늘어나 도트가 뭉개진다.
