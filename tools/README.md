# 스프라이트 도구

`prototype/newbie-quest-demo.html`의 캐릭터를 레이어로 쪼개는 과정을 남겨 둔 곳.

원본 일러스트 한 장에서 `assets/sprites/*.png` 다섯 장이 나오기까지 순서:

1. **배경 제거** — 굵은 검은 외곽선을 연결 요소로 잡고, 테두리에서 flood fill 해 바깥을 지운 뒤
   구멍을 메운다. 64px 격자로 내리고 색 수를 22개로 줄인다.
2. **레이어 분리** — 정수리에서 flood fill 해 머리카락을 뜯어내고(눈·눈썹은 보호),
   몸통 박스 안에서 남색 계열과 그에 붙은 외곽선을 상의로, 엉덩이 아래를 하의로 가른다.
3. **소품 제거** — 커피 텀블러와 서류가방을 지운다. 소품이 겸하고 있던 외곽선까지 사라지므로,
   드러난 밝은 가장자리에 1px을 다시 찍는다. 이웃이 하나뿐인 픽셀은 가시가 되므로 걸러낸다.
4. **왼팔 복원** — 커피를 지우면 왼팔이 같이 날아간다. 오른팔 영역을 좌우 반전해 왼쪽에 이식하고
   2px 안쪽으로 당겨 몸에 붙인다.
5. **다리 골 파기** — 원본은 두 다리가 붙어 있고 허벅지 쪽 골이 거의 없다. 한 덩어리로 보여서
   한쪽 다리가 뜯겨 나간 것처럼 읽힌다. 줄마다 가운데에서 가장 어두운 칸을 찾아 무릎 위까지 골을 판다.
   이미 골이 파여 있으면 건드리지 않는다.

각 단계마다 눈으로 확인해야 한다. 자동화만 믿으면 얼굴에 멍이 들거나 팔이 사라진다.
