# 플레이테스트 에이전트

사람 대신 에이전트에게 게임을 끝까지 플레이시키고, 막히거나 어색한 지점을 보고받는 루프다.
에이전트는 코드를 고치지 않는다. 보고서를 받아 버그는 바로 고치고, 취향이 걸린 것은
주인에게 묻는다.

## 돌리는 법

1. `harness.mjs`가 프로토타입을 새 브라우저로 연다(Playwright 필요: `npm i -D playwright`).
2. 아래 두 브리핑 중 하나를 에이전트에게 준다. 둘은 서로 겹치지 않아서 동시에 돌려도 된다.
3. 보고서는 심각도(막힘/불편/다듬기)와 분류(버그/판단 필요)로 온다.

비용을 줄이려면 에이전트 모델을 한 단계 낮춘다. 1차는 가장 큰 모델로 돌렸고 두 에이전트가
합쳐 약 40만 토큰을 썼다. 스크린샷을 직접 보고 판단하는 일이라 토큰 대부분이 이미지다.

## 브리핑 A — 처음 켠 취준생

온보딩 → 홈 지도 → 말 걸 사람 찾기 → 퀘스트 하나(일부러 틀려 보기) → 옆 맵과 미니맵 이동 →
사건 한 편 → 보스 → 내 방 → 다른 탭들. 390×844와 360×640 두 크기. 코드를 읽지 않고
화면만 보고 다음에 뭘 할지 알 수 있는지를 본다.

## 브리핑 B — 중반 시스템

장비 조합과 지도 스프라이트 일치, 여러 칸 세간 배치(벽·문·붙박이 책상·다른 물건·내가 선 칸),
거처 올리고 내리기와 이사 정리, 방 안 동선, 라면, 새로고침 뒤 상태 복원, 미니맵 이동.
상태 세팅은 `page.evaluate`로 해도 되지만 그 뒤로는 사람처럼 누른다.

## 1차 결과 (2026-09-27)

두 에이전트가 찾은 것 중 버그 24건을 고쳤다(커밋 `d20f6f9`). 가장 컸던 셋:
실패한 퀘스트가 완료로 찍히던 것, 정답이 전부 첫 번째 보기였던 것, 방 안에서 이사하면
벽 속에 갇히던 것. 판단이 필요한 것은 따로 물었다.

## 2차 결과 (2026-09-27, Sonnet 한 명)

실제 경제, 첫 대사, 지역·보스 잠금, 사건 결말 요약을 봤다. 막히는 곳과 콘솔 에러는 없었다.
고친 것은 셋이다. 지도에서 잠긴 보스를 누를 때도 지금 스탯을 같이 보여 주고, 결말 요약은
고른 것을 전부 보여 주고, 튜토리얼 마지막 줄이 무엇을 누르라는 건지 분명히 했다.
토큰은 약 18만으로 1차의 절반 아래였다. 중간에 사용량 한도에 걸려 한 번 끊겼다가 이어서 끝냈다.

## 3차 결과 (2026-09-27, Sonnet 한 명)

단계별 튜토리얼, 걷기 네 박자, 느낌표 말풍선, 건물 안 여덟 곳과 숨은 것들, 캐릭터 상태창, 도감을 봤다.
콘솔 에러와 막히는 곳은 없었다. 고친 것: 퀘스트 결과 제목을 한국어로, 튜토리얼이 한꺼번에 몰려
뜨지 않게 45초 간격, 건물 안과 내 방을 1.5배로 당겨 위아래 빈 곳을 줄임, 맨 아래 줄에서 방향키에
캐릭터가 가리지 않게 카메라가 지도 밖으로 조금 더 내려가게 함. 넌센스 퀴즈는 틀리면 대화가 끝나고
다시 말을 걸어야 하는데, 보기가 셋뿐이라 바로 다시 고르게 하면 찍기가 되어서 그대로 뒀다.

## 4차 결과 (2026-09-28, Sonnet 두 명)

한 명은 새로 켠 사람처럼 오프닝부터 첫날 흐름을 플레이했고(약 33만 토큰), 한 명은 스크린샷 없이
전역 데이터만 뽑아 콘텐츠와 플레이타임을 감수했다(약 13만 토큰).

- 콘텐츠: 퀘스트 32개·96문항, 사건 4, 보스 3, 백과 가이드 4, 거처 15단계, 여행지 3, 숨은 것 10.
- 플레이타임: 첫날 15~20분, 퀘스트 하나 1.5~2분. 하루 3개 배정이라 새 문항은 9~12일이면 바닥난다.
  거처 끝까지 7~14일. 그 뒤로는 복습과 미니게임만 남는다.
- 정보: 주거 계약·전세사기·실업급여·근로계약은 출처까지 탄탄하다. 연말정산, 프리랜서 3.3%,
  청년 정책금융, 대출·리볼빙, 보이스피싱·중고거래 사기, 구독 관리, 실손보험, 직장 내 괴롭힘은 없다.
- 고친 것: 이사 정리에 '나머지 알아서' 버튼(열네 개를 하나씩 확인하던 것), 오프닝 이야기 화면을
  읽을 수 있게 늘림, 생활비(식) 퀘스트 기본 출처를 국세청에서 한국소비자원으로.
